# 最终数据集定稿 v2（4k 长段、分阶段、≤25 min 单元）

2026-10-18。**取代** `最终数据集定稿_20261013.md`（8k 版，保留作对照）。改动原因：GPU 只能按 ≤30 min 单元排队；分阶段到达下各段互不耦合，可拆成独立单元离线精确拼接；4k 长段与 8k 比值一致（`sim/half_hour_final.log`）。

## 1. 不变的部分

模型 / 硬件 / 布局 / B_max / prefill 上限 / 显存常数、对比方法（WeaveTP、固定 TP2、固定 TP4）、切换计划规则（长段第 1 条接纳前 2→4，最后一条完成后 4→2）、tokenizer 规则、两种吞吐口径、TTFT 记录——全部沿用 `最终实验配置_20261012.md` §1–§4、§6。

## 3. 池（与 8k 版相同的过滤规则）

| 池 | 规则 | 服务器位置 |
|---|---|---|
| 长 4k | 五源长输出池，总长 3800–4200、输入 ≤ 800、输出 ≥ 64 → 约 576 条 | `/data/ubuntu/lxh/weavetp/e2e_prep/data/{s1k_1.1,limo,longwriter_6k,sky_t1_17k,openr1_math}/` |
| 短 P（图 1） | ShareGPT 输入 ≥ 512、输出 ≤ 64 → 9,810 条 | `/data/ubuntu/lxh/weavetp/e2e_prep/data/sharegpt/ShareGPT_V3_unfiltered_cleaned_split.json` |
| 短 B1–B4（图 2） | ShareGPT 输出 ≤ 64，输入 [32,128) / [128,256) / [256,512) / [512,1024] → 2,959 / 3,940 / 11,624 / 3,775 条 | 同上 |

**数据来源与解析（必须复刻 `longout_profile.py`，该脚本在服务器 `e2e_prep/` 下，副本见 `tools/longout_profile.py`）：**
- HF 仓库：`simplescaling/s1K-1.1`、`GAIR/LIMO`、`THUDM/LongWriter-6k`、`NovaSky-AI/Sky-T1_data_17k`、`open-r1/OpenR1-Math-220k`（只取 `*default*.parquet` / `data/train-*.parquet` 的第 1 个分片）；已由该脚本经 hf-mirror 下载到上表目录，先 `ls` 确认再决定是否重下。
- 每源只取按文件名排序后前 3,000 条可解析样本；解析顺序：`messages[]`/`conversations[]`（输入 = system + user/human 拼接，输出 = 第一条 assistant/gpt）→ s1K 的 `question` + `deepseek_thinking_trajectory + "\n" + deepseek_attempt` → OpenR1 的 `problem` + `generations[0]` → `question|problem` + `solution`。
- 输入 token = 不加特殊 token 计数 + 1（BOS），输出不加。
- 硬校验（精确）：过滤 `输入+输出 ≤ 16384 且 输出 ≥ 64` 后各源条数 / 输出 p50 = s1k_1.1 840 / 9009、limo 760 / 5889、longwriter_6k 2939 / 4603、sky_t1_17k 2931 / 3321、openr1_math 2912 / 4901；4k 池 576 ± 2%，8k 池 472（对照用）。不符停下报告，不放宽。
