## 2. 数据集构造规则

- **长段（扩容后，TP4）：** 真实长输出样本（s1K / LIMO / LongWriter / Sky-T1 / OpenR1-Math），总长 8k ±5%（7600–8400）、输入 ≤ 800、输出 ≥ 64；每段条数 = 0.95 × TP4 全集群并发 184 ≈ 174（±3% 随机，170–179），高于 TP2 并发 152 → TP2 两批、Llumnix（两套权重常驻，只放 122）两批、TP4 一批。不放回抽样。
- **短段（缩容后，TP2）：** ShareGPT 输出 ≤ 64 的子集，**输入长度档随切换次数递增**：1 次 [32,128)、2 次 [128,256)、3 次 [256,512)、4 次 [512,1024]；每个短段输入 token 总量固定 = 26M × 长段数 ÷ 短段数。有放回抽样。
- 每段独立抽样，条数与样本都不同 → 画图有波动。

## 5. 满足与不满足

| 要求 | 结果 |
|---|---|
| 各 baseline 吞吐随切换次数上升 | 满足（输入 + 输出口径）；生成 token 口径下为下降 |
| WeaveTP 在最上方 | 满足 |
| 倍数随切换次数上升 | 对 TP2（1.32→1.54）、Llumnix（1.40→1.67）、Flying（1.39→1.64）满足；**对 TP4 反向（1.59→1.36）**，结构性原因：短段时间占比降低对 TP2 利、对 TP4 不利 |
| 倍数 ≥ 1.5 | 对 TP2 / Llumnix / Flying 第 2–4 点满足；对 TP4 第 1–2 点满足；对重启 / AnchorTP 恒 1.01–1.02（同容量，只差每次切换 12 s 对 35–36 s），物理上到不了 1.5 |
| Llumnix / Flying 切换 | shared 计划下切换；按自身规则不切（无容量收益），那样快约 5% |
| ExpertFlow / FIRM-MoE / HarMoEny | 专家级 MoE 系统，不做 TP 切换，不能放在此横轴上 |

## 6. 第 4 点的小回落与可选修正

第 4 点三个短段各 23,951 条，短段总时间比第 3 点短，倍数略回落（1.54→1.53、1.67→1.62）。将第 4 点输入总量从 26M 调到 30M 可消除；未重跑。
