# WeaveTP 组件消融：pause 入口服务器命令（SL3061，xnode 加 SL3060）

## 基本信息
- **代码**：分支 `codex/ablation-8gpu`，实现提交 `88d32413be527ba45a6b24627bd0456352a7aa31`，基于 `beda9f1`。说明见 `code/current/tools/resharding/ablation/README.md`。
- **运行规则**：
  - 每次只跑一个脚本，不要并行。
  - 不用 tmux；担心断线时可以在命令前加 `nohup … &`。
  - torchrun 进程数取 `nvidia-smi -L` 看到的 GPU 数；xnode 每台机器固定用 GPU0–3。
- **中断后清理**：在相关机器上执行 `pkill -f weavetp-ablation-`。每次 launch 结束时脚本也会自动执行。
- **预计时长**：按 run_r1 实测估算（27 层 setup 约 15 s，规划 1–7 s，每次 pause 迁移约 3–5 s）。每次 launch 结束时会打印实际耗时 `[launch] … elapsed_s=`。

| launch | 预计时长 |
|---|---|
| pause smoke | 约 3 min |
| pause row_b | 约 6 min |
| pause row_a（n=3/7/14 三次合计） | 约 2 min |
| pause xnode | 约 3 min |

3. 在每台用到的机器上执行，代替上面的 `git fetch origin` 那一行，然后照常执行 `merge-base`：

## 3. checkout（两台机器都执行）
```bash
git -C "$REPO" checkout --detach 88d32413be527ba45a6b24627bd0456352a7aa31
git -C "$REPO" rev-parse HEAD        # 两台都必须输出 88d32413be527ba45a6b24627bd0456352a7aa31
sha256sum "$REPO/code/current/tools/resharding/ablation/cpu_flood.py"   # f7659988…d8c9ea
export ABL="$REPO/code/current/tools/resharding/ablation"
export ROOT=/data/ubuntu/lxh/weavetp/ablation/run_r2
mkdir -p "$ROOT" && df -h /data
```

`ROOT` 在两台机器上用同一个路径，两台各自写本机的输出。换终端后，需要重新 source env.sh，并重新 export `ABL` 和 `ROOT`。

## 4. pause smoke（约 3 min，可以和别人同卡运行）
```bash
bash "$ABL/run_pause_smoke.sh"
echo "exit=$?"
```

- 退出码必须为 0。数值校验失败、显存不足、灌流进程没有全部就绪，都会导致非零退出。
- 查看 `$ROOT/pause/smoke/run.log` 末尾这几项：
  - `[memory] after build`、`[memory] end`：每张卡的峰值显存；
  - `[check] flood=0:24,1:24 {...}`：生效检查，看有没有 `WARNING: inactive`；
  - `[smoke] L1..L4`：T_data 中位数、T_data 的 CV、wave 设备时长 CV 的最大值、改路字节、发送端 max/mean、瓶颈 rank 分布；
  - `[smoke] T_data median ratio L3/L2=… L4/L3=…`。
- `$ROOT/pause/smoke/metadata.pkl` 是导出的 planner 元数据，留着随包带走。

## 7. pause xnode（约 3 min）
两台机器都完成第 1–3 步，并且两台的 `rev-parse` 输出相同 SHA 之后再启动。启动顺序：
1. 先在 SL3061 启动（master，承载 rendezvous store）：
   ```bash
   NODE_RANK=0 bash "$ABL/run_pause_xnode.sh"
   ```
2. 再在 SL3060 启动：
   ```bash
   NODE_RANK=1 bash "$ABL/run_pause_xnode.sh"
   ```

两台机器的预检各自检查本机的磁盘和 GPU0–3。结果写在 SL3061 的 `$ROOT/pause/xnode`；SL3060 只留 `run.log` 和 GPU 快照。
